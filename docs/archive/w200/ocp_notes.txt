opencod2. Same lineage as our oc/ tree (Mac-1.3 STABS decompile), then hand-edited for behaviour (dvar_value()

FxPrimitives       Cylinder/Flash etc. are placeholder structs (int _placeholder); Emitter has partial fields. No class layout data.
