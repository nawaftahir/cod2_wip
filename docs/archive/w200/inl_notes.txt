RULE (PINNED: Ghidra decompile + oracle cave_w.s/patch_w.py, logs in fp_t/build/ordq.txt)
Plain /LTCG runs with 0x108a91ec=1 and 0x108a9208=1. So every site of a callee that has
call-graph data ([sym+0x99]) goes through the cost model 0x1078d1aa, called from 0x1078cf54
(hooked at 0x1078d026). The revert check 0x107284d5 (called from 0x1078da87) only runs for
callees without that data (624 sites in the whole link). It does not run for NET_CompareAdr.

0x1078d1aa, second branch (edge flags [site+0x18] bit 2 clear):
  cost = size[sym+0x81] - argcost[0] - argcost[1]     (+ a caller-size penalty, only above 9000)
     argcost comes from 0x1078d03c and is per SITE: [0] = 1, plus 5 per actual arg of kind
        3/4/7-9 (const/addr/mem), or 2 per arg of any other kind; [1] += 3 if the result
        is stored to a memory var.
     kind weights [2..6] are 0 here; caller-count discount is OFF (0x10881d14=1, 0x108819ec=0).
  if cost < 9+5=14            -> inline (unless the veto 0x1078f15a fires)
  else frequency path:  c = per-SITE estimated execution count [site+0x10] (64-bit, 1e8 = fn entry)
        c == 0                -> REFUSE
        c <= 1e8: r = (cost*1e8/c + 6*cost)/7     else r = (cost*1e8/c + 2*cost)/3
        r >= 71               -> REFUSE, else inline (subject to the veto 0x1078f15a).
  Constants read at runtime: 0x108819a8=9, 0x10881954=5, 0x10881958=2, 0x10881934=3,
  0x108819a4=71, 0x10881994=7, 0x10881998=3.
Static count estimate: CORRECTED 10-30, see FREQUENCY ESTIMATOR at the end. Short form: entry 1e8,
equal split per out-edge (if-arm x0.5), loop header sends 10x its entry flow; natural loops give every
exit an equal share of the entry flow (renormalised), non-natural loops (for(i=0;;i++) layout) do not, so
only those keep x5 after the loop (5x, 25x...).

So two sites of one callee in one caller differ ONLY by their arg kinds / result use, or by
their block count. For a callee at exactly cost 14 (NET_CompareAdr: size 19, two by-value
struct args = 1+2+2 = 5 -> 14), every site takes the frequency path. A site is refused when its
block is cold (below ~3.4% of entry for cost 14) or its count is 0.

     (64-bit integer division) among the undone out-edges. After 3 passes anything still undone = 1e8.
