RULE (from REGALLOC.md rounds 5-10, re-confirmed on SND_RestoreStreamChannel pick logs)
- Pop order per class worklist: higher n3 first; equal n3 -> larger n17 first.
  n3 = sum over regions of (ref units x region weight x referenced-candidate count) minus
  region weight where the node is live but unreferenced. n17 = IL index of the last bound ref.
- Pick: cost[r] = neighbour affinity counts (+100*n16 if a neighbour has one free reg left),
  minus own copy affinity; scan eax,ecx,edx,esi,edi,ebx,ebp; strictly lower cost wins.
- A value live across a call has no eax/ecx/edx. If its free set is one reg (cost 2801 style)
  it is NOT a pop tie: an earlier-popped temp took the reg it wanted. Fix that temp, not the var.
