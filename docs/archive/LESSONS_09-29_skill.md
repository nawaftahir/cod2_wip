# Client recon — lessons from reverted attempts (read BEFORE editing; append AFTER every revert)

Purpose: stop re-trying edits that already failed. One line per lesson: what was tried → measured result → why → rule.
Numbers are `./m.sh` unique bytes (base 852,481 = 60.52% on 09-29).

## Triage before touching a function (2 min, saves a 100 s build)
1. `../structdiff.py` class: `regalloc`/`sched` (same instrs, diff order/regs) = LTCG tie → SKIP unless a source-shape hint is already in the catalogue.
2. Retail passes an arg in a register (`ecx`/`edx`/`eax`) where ours pushes = LTCG custom convention → cannot be forced from source. SKIP (SE_GetString, Menus_OpenByName, FS_FOpenFileRead_Internal, CG_DrawInformation, SV_Netchan draw helper).
3. Diff = missing call / missing else-branch / missing block → real source gap, worth doing, BUT first check whether the missing code drags in client types (server TUs have no `/I oc`; see below).
4. Function is a known tie-noise fn (SV_ArchiveSnapshot, MSG_WriteDeltaPlayerstate, nb_decode, PC_EvaluateTokens 2.6 KB) → a loss there after your edit is usually ripple, not your bug. Still counts against the commit gate: revert unless net ≥ base.
5. Edit touches a widely-inlined helper (FS_UseSearchPath, TempMalloc, RemoveRefToValue, Dvar_*, SND_*) → predict a ripple; probe in ONE build before polishing.

## Structure facts that prevent wrong edits
- Server-side TUs (`src/server`, `qcommon`, `game`) compile WITHOUT `/I oc`; they cannot include `common_types.h`. Client types must be re-declared locally (partial struct with same name mangles identically) or the code goes in an oc TU. Cross-TU helper = stack convention, same-TU static = LTCG may pick ecx.
- oc `static inline always_inline X_core` helpers are NOT inlined by MSVC; retail one real function → merge helper into it.
- Placeholder `imp_*` / `*(dvar_t**)_dvar_*` globals hide address-taken status and double-deref bugs; use the real symbol.
- fdiff takes the RETAIL VA, not our map address. m.sh only greps "unique bytes" → check for `error` lines yourself.
- Commit gate: gain/loss script; net ≥ `cmp_base.json`, then copy cmp.json → cmp_base.json. `$L…`/`__ehhandler$` rows are noise.
