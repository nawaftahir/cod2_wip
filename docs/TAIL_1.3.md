# CoD2MP_s.exe 1.3: tail triage (11-07)

Generated by `tools/tail13.py` (clean build of `client/1.3/main` 587bb16b; ANCHOR = retail 1.3). Layout is exact (every obj span
equals retail, text drift 0 except the libcmt order block and HTEvtLst), so each function is compared with retail at its own address.
Normalization: addresses masked (relocation), then registers, then stack offsets, then mnemonics; the first level that makes both
sides equal gives the class. The class is a first guess from the instruction diff, not a proof; confirm in the real function.
